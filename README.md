# مستودع محتوى «نور» (noor-content)

هذا القالب هو المستودع الذي ينزّل منه التطبيق أصوات الأذان، ولاحقًا تحديثات المحتوى. انسخ هذا المجلد إلى مستودع GitHub **عام** مستقل باسم `noor-content`.

## الإعداد مرة واحدة

1. أنشئ على GitHub مستودعًا عامًا جديدًا باسم `noor-content`. أنت من يُنشئه بحسابك.
2. انسخ محتوى هذا المجلد (`tool/content_repo_template/`) إلى المستودع، ثم ارفعه (push).
3. عند بناء التطبيق، أضف عنوان المستودع:

   ```bash
   flutter build apk --release --split-per-abi --target-platform android-arm64 --dart-define=NOOR_CONTENT_URL=https://raw.githubusercontent.com/<اسم-حسابك>/noor-content/main
   ```

   بدون هذا السطر يعرض التطبيق الأصوات المدمجة فقط، ومعها رسالة «أصوات أخرى قريبًا».

## إضافة أذان جديد

1. **الترخيص أولًا:** لا يُضاف تسجيل إلا بأحد أمرين:
   - موافقة مكتوبة موقّعة من المؤذن على النموذج `docs/audio/muezzin_consent_form_ar.md`. احفظ النموذج الموقّع عندك، **ولا ترفعه للمستودع أبدًا**، ففيه بيانات شخصية.
   - ترخيص حر يسمح بإعادة النشر، مثل CC0 أو CC BY، ويُذكر رابطه.
2. حوّل التسجيل إلى MP3 بجودة 128 إلى 192 kbps. يكفي هذا للأذان ويبقي الحجم صغيرًا.
3. ضع الملفات في `adhan/files/` بأسماء إنجليزية بسيطة، مثل `eg_ahmed_full.mp3` و`eg_ahmed_fajr.mp3`.
4. أضف مدخلًا في `adhan/voices.json`:

   ```json
   {
     "id": "eg_ahmed",
     "nameAr": "أذان بالمقام المصري",
     "nameEn": "Egyptian maqam Adhan",
     "muezzinAr": "الشيخ أحمد …",
     "muezzinEn": "Sheikh Ahmed …",
     "country": "EG",
     "license": "Consent (Noor)",
     "consentRef": "2026-12-01 signed form, kept offline",
     "credit": "تسجيل الشيخ أحمد …، بموافقته المكتوبة لتطبيق نور",
     "fullFile": "eg_ahmed_full.mp3",
     "fajrFile": "eg_ahmed_fajr.mp3"
   }
   ```

   - `id`: حروف إنجليزية صغيرة وأرقام و`_` فقط.
   - `fajrFile`: اختياري. إن لم يوجد، يبقى الفجر بنغمة الهاتف، لأن أذان الفجر فيه «الصلاة خير من النوم».
   - `consentRef`: مرجع داخلي للنموذج الموقّع، **وليس صورة منه**.

5. شغّل الأداة من مجلد المستودع، فتحسب الحجم والبصمة (SHA-256) لكل ملف:

   ```bash
   python -I ../Warchty/tool/build_adhan_catalog.py adhan https://raw.githubusercontent.com/<اسم-حسابك>/noor-content/main
   ```

6. ارفع التغييرات (commit ثم push). يظهر الأذان في التطبيق عند فتح «أصوات الأذان» التالية.

## ما يفعله التطبيق

- لا ينزّل القائمة إلا عند فتح «أصوات الأذان»، ولا ينزّل الملف إلا بعد أن يضغط المستخدم «تحميل» ويرى الحجم والمصدر والترخيص.
- يرفض أي ملف لا يطابق حجمه وبصمته ما في القائمة، ويحذفه.
- يحفظ الملف داخل التطبيق، فيعمل الأذان بلا إنترنت.
- لا يُرسَل أي حساب ولا بيانات شخصية. GitHub يرى طلب التحميل فقط، كأي موقع.
